# 0.6.0：脚步、模型后坐与三帧翻滚

所有玩家及敌人使用同一套实际位移驱动的脚步状态。待机不绘制脚，移动时仅迈出的一只脚从身体前缘露出，左右循环；脚层位于上身下方，缩回时藏入身体。停止、顶墙、攻击原地蓄力、暂停、翻滚与死亡时不继续摆脚。女主、军人、普通敌人和代码角色分别调整鞋的位置与颜色；前方以角色朝向定义，上身继续跟随瞄准，支持横移和后退。

实际开火事件驱动上身后坐，USP／冲锋枪／步枪／霰弹枪分别后退约 1／1.3／1.8／2.3 个逻辑像素，伴随约 0.8～1.8 度左右交替摆动，0.085～0.13 秒回正。贴图角色、代码角色、火光、近场光、烟雾发射与抛壳挂点共用视觉变换；地面脚步、物理位置和实际瞄准保持独立。空弹匣、换弹和翻滚期间没有虚假开枪后坐，暂停、死亡和重开清除瞬时状态，连续射击偏移有界。

重新生成女主与军人两套三帧 RGBA 翻滚图集：低姿收身、肩背翻转、落地起身。中段可以露出背部／身体侧面，不再要求每帧看到头顶。所有帧均无可见武器，完整翻滚期间隐藏站立持枪模型；最后 10% 也保留恢复帧，结束后才恢复武器。女主／军人显示尺寸分别调整至 64／70，使紧缩身体与站立体量衔接。代码绘制兜底也包含三个空手姿态。

翻滚的 0.30 秒持续时间、约 132 像素位移、2.4 秒冷却和碰撞规则沿用原版。宿舍关卡、敌人配置、抽卡和培养沿用 0.5。
