## 阅读注意

- 这些文档是**当时的原始记录**，为保留证据链，其中的版本号、测试项数、本机绝对路径（`E:\cocos\...`、`E:\AIGame\...`）与目录名均未改写，不代表当前仓库结构或可复现路径。
- 记录中引用的 `*.log`、`*-results.json`、`*-browser.mjs` 与大量截图属于本地一次性产物，**未纳入版本库**；原 `chrome-*` 浏览器 profile 缓存目录已清理。
- 浏览器验收使用 Chrome CDP 桌面与 Android 模拟触摸，不等于实体手机或微信真机；文档本身也逐轮注明了这一限制。
- 当前可复现的自动化入口是 `npm run check`（类型检查 + 10 个回归脚本）与 `.github/workflows/ci.yml`。把 CDP 脚本整理为 `tools/e2e/` 并提供稳定调试接口，仍列在 `docs/ARCHITECTURE.md` 的技术债中。
