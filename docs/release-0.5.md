# 0.5.0：校服女主与静默宿舍

默认出战角色改为参考图女生，暂名“星野”：黑长发、银色 X 发夹、深蓝校服与格纹裙，沿用军人素材的写实俯视材质。武器为 USP 消音手枪，12 发弹匣、单发 26 伤害、0.27 秒射击间隔、1.15 秒换弹，100 初始生命。枪口采用消音器末端挂点，小火光、弱近场光、更轻的镜头后坐和独立消音音效；保留烟雾、抛壳、走路回弹，使用专属收身／翻滚两帧图集。

第一关改为校园宿舍楼。南侧走廊连接 101 寝室、102 寝室和东侧洗衣房／楼梯间；两间寝室各有四张床、两张书桌与储物柜，洗衣房有洗衣机和储物柜，东北楼梯为撤离口。共 11 个敌人，包含近战、远程与首领。各区域首次进入激活敌人，可自由选择搜索顺序，全部清理后撤离。

床、书桌、柜顶与两类地面使用新增 ImageGen 素材。墙、窗台、门、标识、楼梯和洗衣机俯视顶面由代码绘制。设施不添加落地投影。沿用暗区去饱和、视距宽羽化、掩体窄过渡、设施表面受光与严格动态单位遮罩；宿舍素材与模拟共用布局数据，不使用一张背景图代替碰撞。

三扇实体门中，两间寝室为 100 耐久可破坏木门，洗衣房为可交互、不可破坏的钢制防火门；同时阻挡移动、视线和子弹。门框预留转轴间隙，双向开门、关门回弹与关键路线均沿用现有规则。

原军人三名加入招募池，渡鸦继续使用原持枪素材，军人翻滚素材保留复用。角色档案和招募界面扩为四名角色。新档只解锁女生；旧档迁移保留资源、各角色培养等级与已招募的雨燕／磐石，原免费初始渡鸦转为待招募。女生始终解锁，首次迁移默认出战；v2 档案此后记住出战选择。渡鸦重新解锁后恢复原培养等级。

- `npm test`：72 项通过，33 项游戏逻辑、19 项表现状态、20 项控制器接线。

- Cocos Creator 3.8.8 Web Mobile 构建：通过，输出 `build/web-mobile`。发布资源清单包含女主、女主翻滚、宿舍道具／地板 SpriteFrame 与消音音效，原军人素材仍保留。
- 新 PNG 尺寸、RGB／RGBA 通道与 Cocos SpriteFrame 导入类型：通过。
- 新增检查覆盖女主默认解锁与军人招募、旧档迁移、宿舍出生点和家具碰撞、三扇门双向完全开启、整层连通与撤离条件、女主枪口旋转缩放、USP 后坐／音效／弱光、素材加载门槛和角色切换后缓存节点锚点。

本轮仍为固定布局的首关样品，尚未加入程序化地图、真实潜行听觉系统或完整行走／换弹动画。消音器目前影响视听反馈，不意味着射击能避免所有敌人激活。

完整生成提示词与素材清单见 `docs/art-prompts-v0.5.md`。旧设施布局仍保留于代码供回归与后续关卡复用；游戏当前入口使用宿舍楼。
