# 0.4.0：设施受光与角色动作

## 本轮行为

- 移除代码绘制的家具、墙体与门扇落地投影；接待区沙发、桌子替换为无落地投影的 v2 透明素材。保留表面材质自身的明暗细节。
- 场景受光分为地面、设施顶面、动态单位。可见设施的顶面恢复正常亮度，仍会阻挡身后的角色和子弹；被另一堵墙或关闭的门完全挡住时，设施不会被点亮。顶面高亮受视距和朝向限制。
- 视距边缘保持 60 像素羽化，掩体边缘改为 12 像素，避免此前同样 60 像素羽化在家具四周形成宽暗圈。
- 走路时按实际位移驱动轻微收缩／回弹及脚步。停步平滑回到原尺寸；碰墙时不持续踏步。
- 枪口改为约 45 毫秒的分层火焰，步枪、冲锋枪、霰弹枪大小不同。贴图模型的枪口为局部坐标 (51.25, 0)，代码模型为 (41, -12)，位置随瞄准和步态缩放同步。火光与环境照明共用挂点，枪管被掩体阻断时不在掩体外生成火焰。
- 每次实际开火生成 3 个轻量烟团及 1 个弹壳。烟雾约 0.24～0.35 秒消退；弹壳侧抛、落地轻弹并在约 1.65 秒内淡出。最多 24 个烟团和 32 个弹壳。烟雾与弹壳的运动碰撞及显示均遵守遮挡。
- 移除震荡脉冲的英雄配置、冷却状态、伤害和清弹逻辑、按钮、Q 绑定、说明、音效文件与音效生成入口。开关门按钮上移至原技能区。低血量间歇闪红继续保留。
- 空格／翻滚按钮播放收身、翻转两个帧图，再恢复站立。翻滚 0.30 秒、移动速度 440，完整位移约 132 像素；保持 2.4 秒冷却、0.28 秒无敌及碰撞子步。三名玩家共用同一组帧图并略作配色区分；素材未载入时有两姿态程序绘制兜底。
- 全部角色死亡后不保留模型、血条、脚下圆环或攻击预警，只生成一滩不规则红色血迹。血迹绘制在地面层，形状稳定，重开清空；死亡敌人已有的命中粒子同时清理。死亡当帧的清房奖励不会把玩家复活。

## 实现入口

- `Core.ts`：移除技能、翻滚时间与位移、死亡血迹和粒子清理。
- `Presentation.ts`：设施表面光照、两种羽化宽度、距离驱动步态、武器挂点和轻量烟雾／弹壳。
- `Art.ts`：无投影家具、两姿态兜底、分层火焰和不规则血迹。
- `Blackout.ts`：资源加载、两帧切换、独立地面血迹层、输入与界面。
- `visibility.effect`：B 通道仅提升设施表面亮度，不能用于揭示敌人或照穿掩体。
