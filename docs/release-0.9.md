# 0.9.0：门外观察与持续存在的敌人

修复进入房间才显示、行动和接受命中的逻辑绑定。所有敌人仍在开局一次生成，显示只由现有严格视线遮罩与柔和视野场决定，近战贴图、远程代码模型与首领一致处理。门缝通视后即可看见敌人，在门外可正常射击；关门、再打开、跨越门槛不会重建或复活敌人。

## 房间状态

| 状态 | 含义 | 触发 |
| --- | --- | --- |
| visited | 玩家实际进入过 | 出生所在区域、首次跨入房间 |
| discovered | 已接触或发现该区域 | 进入、开门／破门、敌人受击、角色看见敌人 |
| alerted | 房间敌人已经警戒 | 起始区域、进入、开门／破门、敌人受击、敌人无遮挡发现附近玩家 |
| cleared | 已发现区域的原有敌人全部阵亡 | 按实际存活敌人判断，与是否进入无关，只结算一次 |

门配置增加连接的两个房间索引，宿舍门对应走廊与 101、102、洗衣房。旧设施关卡的三扇门也有明确连接关系。开门／破门只警戒对应连接房间，不通过门中心所在区域猜测，也不会唤醒整张地图。

未警戒敌人原地待机，每 0.2 秒进行一次轻量感知。AI 当前采用 360 距离的全向无遮挡检测；玩家可看见更远敌人时先记录发现，不必同步警戒。警戒后正常逐帧运行原有寻路与攻击，首次警戒将攻击准备冷却至少保留 0.35 秒，近战 0.38 秒、远程／首领 0.7 秒攻击前摇继续生效。反复开关门不会重置已警戒敌人的冷却。当前为房间级警戒，未加入真实声音传播或休眠巡逻。

全部存活敌人始终参加子弹命中和门扇扫掠碰撞，休眠不会令角色无敌或允许门扇穿过身体。门仍受物理阻挡，敌人实际挡住转动范围时保留“门被挡住”提示。房间外击杀会记录发现、清房并恢复一次生命，之后进入不会重复奖励。死亡角色继续只留血迹。

小地图独立显示未知、已发现、已探索与已清理区域，继续隐藏敌人位置。敌人追进原本已清理的走廊时，当前区域目标改为“应对追击”，避免显示“区域安全”。
