# 0.3.0 连续羽化视野与战斗反馈

## 本轮改动

参考图要求暗区能够辨认场景设施，且与亮区使用同一套材质。本版移除单独的低透明度代码底图和六档径向色带，环境只绘制一次，合成时根据视野场在冷灰暗色与正常材质之间连续混合。

## 渲染结构

- 环境相机输出完整建筑、家具、地板与门到环境 RenderTexture；明暗区共享这份图像。
- 动态对象由另一相机输出到透明 RenderTexture，角色、敌人血条、弹道、尸体与粒子始终经过严格视线多边形裁剪。
- UI 相机只绘制最终合成画面和 HUD。两个离屏相机都排除 UI 层，避免递归采集最终画面。
- 合成材质使用 320×180 RGBA 视野贴图：R 为连续羽化，G 为严格可见区。默认 60 逻辑像素宽，羽化仅向合法可见区内部收缩。
- 羽化采用扫描线填充、双向距离变换和 smoothstep，不对遮挡轮廓做向外模糊，因此不会用羽化照亮墙后的区域。纹理线性采样，消除分档色带。
- 几何视线遮罩每帧更新。羽化贴图通常 30Hz 更新，转向、移动或门形变超过阈值会提前刷新；镜头震动及贴图缓存间的小幅位移单独补偿。
- 暗区亮度系数 0.27、保留色彩比例 0.10，加冷灰蓝偏色。动态对象在过渡带渐隐，近身玩家保持可辨认。HUD 不参与调色和震动。

## 战斗反馈参数

| 反馈 | 初始参数 |
| --- | --- |
| 枪械后坐 | 冲锋枪 1.8、步枪 3.2、霰弹枪 5.7 逻辑像素的初始冲击 |
| 镜头回弹 | 阻尼弹簧，每次冲击限幅，持续射击不无限累积 |
| 枪口光 | 140 像素，霰弹枪 160 像素；65 毫秒衰减；受严格遮挡限制 |
| 受击红色 | 真实扣血触发，180 毫秒衰减，边缘强、中心弱 |
| 低血量 | 25% 进入、30% 退出；正常周期 1.5 秒，10% 以下为 1.1 秒 |
| 低血量波形 | 每周期前 42% 为平滑脉冲，其余时间无脉冲 |
| 命中提示 | 独立 75 毫秒短音效，同一时间段限频 |

视觉状态独立于 Battle，不修改角色的物理位置、伤害或碰撞。暂停和结算清除瞬时效果，新行动重置全部反馈状态；暂停后继续保留低血量阈值的迟滞逻辑。

## 素材与场景依赖

没有新增图片。已有五张素材在统一环境层与动态层继续使用。新增 `visibility.effect` 为场景预加载依赖；旧场景缓存缺少该引用时会回退到异步加载，材质准备好之前保留主菜单。

新增命中音效 `assets/resources/audio/hit.wav`，可用 `node tools/generate-hit-audio.mjs` 重新生成，不需外部音频服务。

## 验证与试玩

测试覆盖连续羽化与凹角遮挡、门损毁后的视野更新、不同遮罩分辨率、镜头限幅和衰减、受击和低血量迟滞、暂停与跨局清理、HUD 稳定、空弹匣不触发开火反馈、离屏相机分层，以及已有门、战斗和养成。

试玩时建议先旋转瞄准方向，检查亮区与灰暗家具是否一致；靠近闭门开火，检查闪光不照穿门；按住步枪连射观察镜头回弹；让敌人命中数次，观察受击闪红与低血量间断提示，再通过清场回血检查提示停止。

测试引擎替身不能验证 GPU 最终显示。H5 构建、材质编译和浏览器／真机试玩的实际结果应分别记录，不互相替代。
