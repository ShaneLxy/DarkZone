# 第四章「断翼行动」剧情规格

> 状态：**已确认基线**（2026-11-17）。本文件是第四章所有后续设计、美术与代码改动的唯一依据。
> 修改本文件前需重新与项目负责人确认；代码实现与本文件冲突时，以本文件为准。
> 相关：[架构与模块索引](ARCHITECTURE.md) · [画风规范与裁切清单](art-prompts-chapter4.md) · [历史验收资料](qa/README.md)

## 1. 核心设定

这是**单向、必然发生**的剧情，不存在"阻止注射""活捉成功""首领被击杀"等分支：

- 人形首领一定会被打到空血，**但不阵亡**，而是给自己注射病毒并成功变身为丧尸王；
- 变身后的丧尸王会**击败前来活捉的队员**，玩家与残存队员继续与其战斗；
- 丧尸王血条清空后**同样不阵亡**，而是留下台词后飞出屏幕；
- 核打击之后，**丧尸王与大量丧尸并未被消灭**（与第 5 点飞走的是同一个个体）。

玩家在这段剧情里的作用是"经历并付出代价"，不是"改变结局"。

## 2. 用户确认的九点流程

| # | 要求 |
| --- | --- |
| 1 | 开场让队员之间用对白给玩家介绍关卡背景和目标 |
| 2 | 落在指定停机空地 |
| 3 | 队员和对方发生阶段性的交火 |
| 4 | 玩家小队突破防线进入敌方指挥部建筑 |
| 5 | 与首领发生枪战；首领空血时不阵亡而是触发给自己注射病毒并变异的剧情，然后成功变身为丧尸王；小队继续和丧尸王战斗。丧尸王血厚、敏捷度高，有飞起砸地的范围伤害技能、蓄力突进技能和普通攻击技能；血条空后不要让其阵亡，而是播放对话，右侧弹出丧尸王的对话框："你们做的只是徒劳而已,末日已经到了!"随后飞出屏幕 |
| 6 | 玩家收到新的任务，撤回到开场时的登陆点进行撤退 |
| 7 | 过程中遭到大量的丧尸围攻 |
| 8 | 军队指挥部发出通告，所有部队紧急撤离，1 小时后进行核打击 |
| 9 | 玩家抵达指定位置并坚守一段时间后触发关卡结局，核打击后丧尸王和大量丧尸并没有被消灭 |

## 3. 已拍板的设计决策

| 项 | 决策 |
| --- | --- |
| 队友存续 | 玩家独战或带残队**取决于玩家在战斗中的发挥**。规则：以变异瞬间仍存活的队友数 `N` 为准，`N = 0` → 玩家独战；`N ≥ 1` → 登场横扫后保留 `min(N, 2)` 名残队继续战斗，其余阵亡/失联 |
| 人形首领 | **会攻击队友**（本轮纠正）。只用武器射击与走位，**无技能**；使用新生成的 AK47 垂直俯视模型 |
| 首领模型 | 只生成**一帧**，正俯视朝上，战斗内程序旋转朝向；对话框头像从同一帧裁切 |
| 丧尸王技能表现 | 使用现有 `op-king` + 程序缩放／位移／特效，**不新增技能帧** |
| 丧尸王飞离 | 战斗内飞离，不切场景：右侧对话框出现时冻结战斗，sprite 沿右上加速位移飞出屏幕并淡出，对话框关闭后解冻，直接接第 6 点 |
| 核打击时间 | "1 小时"是**叙事时间**，HUD 常驻"核打击窗口"标记，不做真实倒计时 |
| 通告时机 | 提前到**撤退途中**（过市集时）插播，不再放在关卡最后 |
| 两次离场 | 第 5 点为"逃走／脱离视野"（战斗内、玩家视角、丧尸王本人说话）；第 9 点为"从爆心烟里带尸群再现"（核爆远景／侦察机视角）。同一贴图、同一头像、台词明确点名 |
| defense 布局 | **要做独立废墟布局**，不再与 city 共用同一张图变灰 |
| 画风基准 | 以 `actors-v2.png` / `city-kit.png` / `props.png` 的写实做旧正俯视为唯一基准；整幅场景插画只做过场，不再进入关卡贴片 |

## 5. 两个「空血不阵亡」节点（实现要点）

现有 `Core.damageEnemy` 在 `hp <= 0` 时会计击杀、生成血迹与碎尸、走死亡流程。两个 Boss 必须加剧情不死标记：

**节点 A — 人形首领**
1. `hp` 钳制在 0，**不计击杀、不掉战利品、不生成血迹／碎尸**；
2. 冻结玩家与队友输入，播放 `op-inject` 注射 → `op-king` 变身；
3. 变身登场时执行"横扫"：对当时仍在场的队友真实扣血（`hurtAlly`），按第 3 节公式结算 `N` 与残队；
4. 生成丧尸王战斗单位，重置其血条。

**节点 B — 丧尸王**
1. `hp` 钳制在 0，同样不进死亡流程；
2. 右侧弹出丧尸王对话框（说话人不以"幽灵"开头即自动右侧，见 `Blackout.placeStoryDialogue`），头像用 `op-king`；
3. 台词后短暂无敌，战斗内飞出屏幕并淡出；
4. 将"丧尸王已逃脱"写入 run 状态，供第 9 点核爆再现复用。

## 6. 队友与状态继承

- 队友损失来自三处：前期交火的杂兵、人形首领（会攻击队友）、变身登场的横扫；
- `defense` 阶段**必须继承**变异结算后的残队，禁止满血重置、禁止人数从 4 变 6；
- 被击倒的队友以"阵亡／失联"表现，与第 9 点台词"没有收到任何地面小队的信号"呼应；
- 队友存活数影响后续台词与过场士兵数量（现有 mutate 过场已按存活数切片，可扩展）。

## 7. 丧尸王战斗规格

复用 `Core` 现有 `type: 'boss'`（hp 650、大体积、血条自动绘制）与 `BruteCharge`（0.78s 蓄力 → 0.58s 冲刺 → 恢复，撞中 42 伤害，冷却 3.1s，含 `bruteChargePreview` 预警线）：

| 技能 | 实现 |
| --- | --- |
| 普通攻击 | 复用 boss 近战／远程攻击分支 |
| 蓄力突进 | 复用 `BruteCharge` + 预警线 |
| 飞起砸地（范围伤害） | 新增：起跳 → 短暂无选中 → 落地环形范围伤害，配 `bruteFootfalls` / `heavyFootfall` 震屏与 `op-impact` 闪光 |
| 血厚、敏捷 | 通过 hp／速度系数调整，**不修改通用 boss 数值**（避免影响第三章 brute） |

| `leader-fight` | 新增 | 首领与队员对射、队友受击呼救 |
| `injection` | 首领 / 队员 | 现有 mutate 台词："你们来迟了。样本已经送往各地，你们留不住我。" / "他手里是注射器！离他远点！"；补队员被击溃的反应 |
| `king-escape` | **丧尸王（右侧对话框）** | **"你们做的只是徒劳而已,末日已经到了!"**（按用户原话，标点原样保留） |
| `new-order` | 指挥部 / 幽灵一组 | 现有 defense 台词："街区已失守！穿过市集，回登陆区等接应。"；补"任务更新"提示 |

| `strike` | 侦察机 / 指挥部 | 现有台词保留，但**明确点名烟里的是丧尸王**；"继续跟踪。其他地区也开始报告感染…" |

## 9. 验收标准

- 九点流程按顺序完整可玩，阶段目标有可交互对象或状态校验，不再只是"清光敌人 + 走到出口"；
- 人形首领与丧尸王两次空血均不阵亡、不计击杀、不生成死亡特效；
- 队友伤亡跨阶段一致，`N = 0` 时玩家独战，`N ≥ 1` 时保留 `min(N, 2)` 名残队；
- 右侧丧尸王对话框与战斗内飞离可见；核爆后同一丧尸王带尸群再现；
- 通告发生在撤退途中，HUD 有核打击窗口标记；
- city / compound / defense 三张图肉眼可区分，defense 为独立废墟布局；
- 结局写入剧情档案／成就；
- `npm test` 增加阶段机、两个不死节点、动态残队与状态继承的回归用例。
