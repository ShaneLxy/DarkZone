# 0.8.0：角色视距与柔和羽化

角色基础配置新增 `visionRange`，`heroStats` 提供正面视距及按比例计算的 `peripheralRange`。女主正面视距从 530 减为 265，近身视距从 140 减为 70，表示各方向的视线距离减半；三名军人保持原值。角色档案显示视距，培养详情显示正面／近身两个数值。视距为本轮基础属性，现有基础、移速、攻速培养不改变它，v3 存档继续兼容。

几何视野多边形、严格角色遮罩、无遮挡视距包络、设施顶面采样和可见性工具函数均使用相同角色视距。墙、家具与房门继续阻挡视线，可见设施顶面照明仍不能揭示后方敌人。

视距边缘羽化由 60 加宽至 96 个逻辑像素，采用连续平滑过渡。近身区域按角色的近身半径调整渐变宽度，逐步过渡到完整的 96 像素羽化，使女主视距减半后脚下和附近正前方仍保持正常亮度。设施与墙体边缘保留 12 像素的窄过渡，避免再次产生家具周围的宽暗圈。设施顶面和地面共用同一自适应包络，视野外设施不会被误点亮。

## 战斗图集拆分

项目外素材 `battle.png` 已按现有 UI 组件分离至 `battle_extracted` 文件夹，共 12 张 RGBA PNG：角色状态、区域标题、时间进度、设置、暂停、小地图、弹药、移动摇杆、射击、换弹、翻滚、手雷按钮。每张保留原图像素、文字和半透明效果，增加 4 像素透明边距；顶部相邻状态栏按原分界分离。原图保持不变。

输出包含 `index.html` 预览、`manifest.json` 原图坐标／尺寸／校验信息和提取脚本；ZIP 为 `battle_extracted.zip`。素材导出不改变游戏 HUD，也不新增手雷玩法。
