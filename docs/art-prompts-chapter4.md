# 第四章美术规范与资产清单

> 状态：**规范已定、四张新资产已落地；代码阶段三批（素材／地图布局，剧情状态机／Boss 战，视野×2／队友编队与交战／地图节奏）均已完成并通过检查与构建**（2026-11-17）。本文件与 [剧情规格](chapter4-story.md) 配套，是第四章所有补图的硬约束。
> 基准资产：`assets/resources/chapter4/actors-v2.png`、`city-kit.png`、`props.png`。裁切定义见 `assets/scripts/OperationArt.ts`。

## 1. 结论：不整体重画

现有素材并非"画得差"：`actors-v2.png` 是 6 帧高质量写实正俯视图集（士兵、持械人员、感染体、首领、注射、丧尸王），`city-kit.png` / `props.png` 是同风格的俯视道具图集。问题在于**两类资产混用与用法**：

- A 类「整幅场景插画」（`coast` / `city` / `landing-field` / `landing` / `compound` / `ending` / `strike-frames`）：带完整建筑、海岸、光照，只用于过场；但 `op-field`、`op-landing` 被当作关卡贴片盖在平铺沙地上，边缘接不上。
- B 类「俯视角色／道具图集 + 地面纹理」（`actors-v2` / `city-kit` / `props` / `aircraft` / `effects` / `street-ground`）：纯黑透明背景、写实做旧。
- 平铺失真：`op-ground`（1672×941）被压成 1280×960 平铺并棋盘翻转；`op-wall`（440×119）被拉伸到 24 厚；`op-floor` 一张裁切拉到 7 个房间。
- city 与 defense 共用同一套几何／屋顶／道具，只把地面染灰。

因此采用：**保留 A 类做过场 + 补 4 类可平铺／可拼接资产 + 改 3 处用法 + 沉淀本规范**。

## 2. 垂直俯视硬约束（所有补图必须遵守）

| 项 | 规范 |
| --- | --- |
| 视角 | 正俯视 90°，只见顶面／头顶；**无建筑立面、无透视缩短、无地平线** |
| 光照 | 单一柔和顶光偏左上 45°，短软阴影；贴片内**不画大范围投影**（避免与平铺地面打架） |
| 色板 | 暖沙 `#c9a97a`、土黄 `#a8875c`、军绿灰 `#5d6152`、炭灰大衣 `#2f3130`、米白围巾 `#ded2b8`、焦土 `#4a4038`、警示红 `#a0463a`；低饱和、做旧、无高饱和霓虹 |
| 质感 | 写实略带手绘质感，与 `actors-v2.png` 一致；边缘干净**无粒子噪点**（现有 `city-kit.png` 边缘有噪点，补图不得复现） |
| 角色／道具图集 | 纯黑或透明背景、角色完整居中、四周留白；`actors-v2` 每帧约 `400×450`，新帧按同尺寸追加即可复用现有加载逻辑 |
| 地面图集 | 2×2 四象限、每象限 512×512，**边缘无缝**；**不得自带建筑／海岸线／大面积阴影**；平铺单元用正方形，避免 1672×941 → 1280×960 的形变 |
| 资产隔离 | **整幅场景插画绝不进入关卡贴图**；过场资产与关卡资产用命名前缀区分 |
| 禁止 | 文字、边框、水印、UI 元素、其他角色、地面环境、投射到地面的长阴影 |

## 6. 落地步骤

1. 生成图先用 `tools/process-chapter4-art.py` 处理，再以第 5 节表内文件名保存到 `assets/resources/chapter4/`：

   ```powershell
   # 角色／道具图集（透明背景）：去水印 + 抠黑底 + 裁到内容边界 + 生成 .meta
   python tools/process-chapter4-art.py <raw.png> assets/resources/chapter4/leader-ak47.png --mode sprite --meta
   # 地面平铺图（不透明）：用同图上方纹理覆盖水印区域 + 生成 .meta
   python tools/process-chapter4-art.py <raw.png> assets/resources/chapter4/ground-tiles.png --mode tile --meta
   # 多帧图集：保留 1024x1024 画布以便按网格裁帧
   python tools/process-chapter4-art.py <raw.png> assets/resources/chapter4/ruins-kit.png --mode sprite --keep-canvas --meta
   ```

   脚本按输出图实际尺寸生成 Cocos `.meta`（自动分配 uuid，写入 `width` / `height` / `vertices` / `uv`）；也可让 Cocos 编辑器打开项目自动生成。
